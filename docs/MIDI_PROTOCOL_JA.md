# WebDJ 汎用MIDIプロトコル

この文書はWebDJの独自マッピング案です。Pioneer DDJ-FLX4 / DDJ-400の公式MIDI仕様ではありません。実際に送受信される番号は `app.js` の実装に合わせて確認してください。

## 基本方針
- MIDIチャンネル: 1
- ボタン: Note On/Off
- フェーダー・ノブ: Control Change (CC)
- MIDI入出力ポートはブラウザがOSから取得できるものを選択します。

## DJソフト連携の確認手順
1. WebDJで「MIDI接続」を許可します。
2. 入出力ポートを選びます。
3. MIDIイベントモニターで入力メッセージを確認します。
4. Windowsの仮想MIDIポートを使う場合は、WebDJの出力先とDJソフトの入力先が同じポートになるよう設定します。
5. DJソフト側のMIDI learnまたはマッピング機能で操作を割り当てます。

## 注意
Web MIDIのポートが見えていることと、DJソフトがそのポートを入力として受け付けることは別です。ブラウザが仮想ポートを作成することもできません。Rekordboxでは一般MIDIコントローラーのサポート範囲がバージョンやモードにより異なり、純正DDJ-FLX4の認識・ライセンス解除・専用機能を置き換えるものではありません。
